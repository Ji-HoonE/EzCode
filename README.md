# 온라인 코딩 테스트 문제 풀이 플랫폼

## 프로젝트 소개
온라인 코딩 테스트 문제 풀이 플랫폼입니다.

## 개발 서버 실행

```bash
pnpm install
pnpm dev
```

### 담당 업무

- **아키텍처**: FSD(Folder Structure Design) 패턴을 적용하여 확장성과 유지보수성을 고려한 구조 설계
- **관리자 페이지 및 게임 모달**: 문제 관리와 사용자 상호작용을 위한 관리자 대시보드 및 게임 모달 구현
- **사용자 인증 및 계정 관리**: 회원가입, 로그인/로그아웃, 소셜 로그인 등 사용자 계정 관리 기능 구현
